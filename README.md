Crescent Bay — a complete open-world crime game in the spirit of GTA 6, built
for make.fun's "Make GTA 6" bounty ($1,666 in USDC). Explore a sun-soaked
coastal city on foot and by car, steal any car, outrun the police under a
wanted system with foot cops, patrol cars, roadblocks and a helicopter, run a
12-mission story arc with fixers Mara and Dex, switch between pistol, SMG and
shotgun, tune your car at the Fixer Garage, flip through three radio stations,
and save across three slots. 8 missions • Wanted 1–5 stars • Traffic &
pedestrians • Steal any car • Day & night • Save game.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no
network requests — plain static files under `game/`.

## Controls

WASD / arrows move, mouse aims, click shoots, Shift sprints. E enters and
exits cars (and accepts dialog). 1 / 2 / 3 switch weapons, Q cycles weapons,
R cycles the radio, Esc / P pauses.
